# 版本发布说明

每次发布是一次**发布列车**：一次列车同时定版并发布全生态组件（server / frontend / 六平台 NAS 包 / 桌面端 / Helm Chart）。

本页分三块读：**当前列车**（正在发布的组件矩阵）、**破坏性变更**（按生效起点列出，一经生效持续有效）、**版本流水**（历史列车一览，只列真正在变的组件与底层版本）。

> 组件各仓的独立变更见对应仓的 Release；工作区级变更见
> [hub 仓 CHANGELOG](https://github.com/pigeonbox/pigeonbox/blob/main/CHANGELOG.md)。
