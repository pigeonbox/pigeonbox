# 使用说明

面向日常使用者与站点管理员的功能手册。部署未完成请先读[快速开始](./getting-started)；环境变量细节见[环境变量参考](./environment)。

## 基本概念

| 概念 | 说明 |
|---|---|
| **分享码** | 8 位字母数字串（如 `4IyC6gZF`），一次分享的唯一标识；取件输入默认大小写不限，站点可用 `download.code_case_insensitive` 关闭折叠改为严格匹配 |
| **取件码** | 6 位快捷码（如 `N7R4NH`），文本/文件分享创建时自动铸造（端到端加密分享除外）；全大写、输入不分大小写，对方凭它同样可以取件 |
| **完整链接** | `http://你的站点/#/share/<分享码>`，对方点开即达分享详情页 |
| **首页取件** | 站点首页即取件页：输入取件码 / 分享码就地取件，无需登录 |
| **过期时间** | 每次分享必须设定：分钟 / 小时 / 天 / 周 / 月 / 年 / 永久，到期自动失效 |

## 发送（创建分享）

首页是取件专属页；发送有独立页面，入口在首页卡片的**「去发送」**链接或顶栏按钮（`/#/send`）。发送页有两个标签：**文件分享** 与 **文本分享**。

![发送页 · 文本分享](/screenshots/send-text.png)
*发送页 · 文本分享标签*

![发送页 · 文件分享](/screenshots/send-file.png)
*发送页 · 文件分享标签（支持多选）*

### 文本分享

1. 切到「文本分享」，输入内容（上限约 1 万字符）；
2. 设定**过期时间**（数值 + 单位）；
3. 「更多设置」里的可选项：
   - **访问保护**：开启后设置取件密码，对方须凭密码取件；
   - **自定义取件码**：指定 3-32 位字母/数字/`-`/`_` 作为分享码（默认随机 8 位）；
   - **端到端加密**：加密密钥在**你的浏览器**生成并嵌入分享链接，服务器只存储密文、无法解密——链接丢了内容就找不回，请勿丢失链接中的 `key` 参数；
4. 点击「安全寄送」。

### 文件分享

1. 切到「文件分享」，把文件拖入上传区或点击选择，支持**多文件**；
2. 过期时间 / 访问保护 / 自定义取件码 / 端到端加密 选项与文本分享一致；
3. 点击「安全寄送」创建。

大文件自动走**分片上传**通道；相同内容的文件重复分享会命中**秒传**（同账号历史同内容文件去重，免落盘直接出码；删除走引用计数保护，仍被引用的物理文件不随单个分享删除），无需重新传输。单文件大小上限由站点配置 `upload.upload_size` 决定（默认 10MB，反代侧 `client_max_body_size` 需同步放开）。

### 分享成功弹窗

创建成功后弹出结果框，交付信息一次给全：

- **6 位取件码**（文本/文件分享同权铸造）：对方在首页输入即可快捷取件；
- **8 位分享码**：发给对方，在首页输入或打开完整链接均可；
- **完整链接**：复制直链发给对方，点开即达；
- **二维码**：扫码取件（手机场景最方便）。

![分享成功弹窗（取件码 / 8 位码 / 完整链接 / 二维码）](/screenshots/share-success.png)
*分享成功弹窗：文件分享附带 6 位取件码，下方三个页签分别给出 8 位码、完整链接与二维码*

## 取件

打开站点首页即是取件页：一个统一的分格输入框，**锁定 6 格**——

![首页 · 取件](/screenshots/home-pickup.png)
*首页即取件页：6 格输入取件码；粘贴更长的分享码/口令会自动按分享码链路处理*

- 输入 **6 位取件码**：填满后自动取件（防抖 700ms，继续输入会取消误触发）；
- 粘贴 **8 位分享码**或更长的自定义口令：整串自动转交分享码链路，回车或点击「取件」进入分享详情页；
- 带密码的分享会**就地展开密码框**，输入正确密码后查看内容，无需跳转；
- 通过完整链接（含 `?code=` 参数）打开时同样直接进入取件流程。

::: tip 兼容性
旧版取件页链接（`/#/retrieve?code=…`）依然有效，会自动重定向到首页就地取件；联邦跨站跳转协议也沿用该形式。
:::

**无密码分享**：文本内容直接显示，文件提供逐文件下载；**密码分享**：先验证访问密码，密码错误可重试；**多文件分享**：逐文件下载，或一键**打包 zip**；**在线预览**：常见图片、视频、音频、文本/代码类文件支持详情页内预览，无需下载。

![分享详情 · 文本内容直出](/screenshots/pickup-text.png)
*分享详情页 · 无密码文本分享直接显示内容*

![分享详情 · 密码验证](/screenshots/pickup-password.png)
*密码分享先验证访问密码*

![分享详情 · 密码验证后查看内容](/screenshots/pickup-unlocked.png)
*密码正确即可查看内容*

![分享详情 · 多文件分享](/screenshots/pickup-multifile.png)
*多文件分享支持逐文件下载与打包 zip*

::: warning 注意
分享过期或取件次数用尽后，将无法访问（同"不存在"处理）。端到端加密分享的内容只有持有完整链接（含密钥）的人能解密。
:::

首页输入框下方还有**「取件 / 发件记录」**：本机浏览器保存的取件与发送历史（仅存本设备，不上传服务器），方便找回最近用过的码。

界面支持**亮色 / 暗色 / 跟随系统**三种主题（顶栏切换，选择保存在本机浏览器）；管理后台入口路径可由站点自定义（`ui.admin_path`，仅入口混淆，安全靠登录鉴权）。

## 注册用户功能

![登录页](/screenshots/login.png)
*登录页*

![注册页](/screenshots/register.png)
*注册页（开放注册的站点）*

开放注册的站点可在页面注册账号（管理员可在后台关闭注册）。登录后获得以下能力：

- **我的分享**：查看名下全部分享，支持**延期**、删除与**回收站**恢复、永久删除；
- **取件历史**：谁取走了你的文件（取件人 IP / 时间 / 累计次数）一目了然；
- **寄件码（反向收件）**：生成一个投递链接（可限定最大文件数、总体积、有效期），访客凭链接向你投递文件——文件自动落成**你名义下**的分享，并有到件通知；
- **通知中心**：接收系统公告与到件提醒，未读数角标提示；
- **API Token**（`pb_sk_` 开头）：在「API 令牌」页创建，用于程序化调用 `/api/v1` 数据面接口（见 [API Token 指南](../reference/api-tokens)）。

登录态为 HttpOnly Cookie（浏览器自动携带，写请求自动附 CSRF 头）；同一账号修改密码或被管理员封禁后，所有已登录会话即时失效。

## P2P 联邦与设备直传（可选，standalone 部署专属）

管理后台「系统配置 → P2P 与联邦」分区集中管理两项 P2P 能力，**保存即热生效**（先立后破、失败回滚，无需重启）：

- **联邦分享（跨站取件）**：启用后本站注册进联邦注册中心（registry 留空 = 官方公共注册中心）。创建分享时使用高熵自定义取件码（如 `fede2e-xxxxxxxxxxxxxxxx`），其他接入同一注册中心的站点可凭该码解析到来源站点并完成取件——内容始终留在源站，注册中心只存哈希路由。跨站跳转沿用 `对方站点/#/retrieve?code=` 协议，旧版节点与新版本互相兼容。
- **设备直传（p2pc）**：两台设备之间端到端加密直传文件，**流量不经过服务器**（打洞优先、加密中继兜底）。server 镜像与 fnos/qnap/openwrt 包均随包 p2pc 二进制，开箱可用；桌面客户端内置 p2pc sidecar。管理员在「设备直传」控制台页发起发送（生成 12 位口令交给对方）/ 凭口令接收（文件落收件区，可一键发布为站内分享）；也可经 MCP 的 `p2p_send` / `p2p_recv` 工具或 `pb p2p` CLI 让 AI 助手/脚本操作。**联邦实例间还可直接推送传输邀请**（对方站点待收/认领，免手工口令交接）。

::: warning 注意
P2P 能力为单机（standalone）部署专属；多副本拆分部署（`PB_DEPLOY_MODE=public/admin`）下自动降级不可用，保存配置会明确报错。直传双端的 wire 协议版本须一致（当前 v4，破坏性变更双端同升）。
:::

## API 与自动化

- **OpenAPI 规范**：后端运行时生成 `GET /openapi.json`，可直接导入 Apifox/Postman；
- **API Token**：`Authorization: Bearer pb_sk_xxx` 调用 `/api/v1` 数据面接口（分享创建/取件/列表等），详见 [API Token 指南](../reference/api-tokens)；
- **MCP（AI 集成）**：`POST /api/v1/mcp` 单端点 JSON-RPC 2.0，19 个工具覆盖分享全生命周期、系统管理、联邦与设备直传（`p2p_*`），默认管理员认证、可开访客级快速分享，详见 [MCP 集成](../reference/mcp)。

## 常见问题

**Q：分享码丢了怎么办？**
分享码是取件唯一凭证（服务端不提供"找回"）。文件分享附带的 6 位取件码可作为快捷备份凭证；端到端加密分享还须保留链接中的密钥参数，两者皆失内容不可恢复。

**Q：提示上传大小超限？**
站点默认单文件 10MB（`upload.upload_size`）。自建站点可在后台「系统配置」调整，并同步放开反代的 `client_max_body_size`。

**Q：为什么有的文件不能在线预览？**
预览按文件类型支持：图片/视频/音频/文本代码类可预览，其余类型（压缩包、办公文档等）请下载后查看。

**Q：匿名访客能上传吗？**
由站点开关「匿名上传」（`upload.open_upload`）决定，管理员可随时在后台关闭。

**Q：忘记管理员密码？**
`PB_ADMIN_PASSWORD` 仅在**首次初始化**（数据库中尚无管理员）时生效，之后修改该变量不会改动已有密码。已有实例忘记密码：由运维在数据库中将 `admin` 用户删除后重启实例，系统会按 `PB_ADMIN_PASSWORD`（未设则 `admin123`，请立即改密）重建管理员。

**Q：局域网/内网无法访问？**
Docker Compose 默认仅本机可访问（安全默认），如需局域网开放请在 `.env` 设 `PB_API_BIND=0.0.0.0` 后重建，详见[快速开始](./getting-started)。
