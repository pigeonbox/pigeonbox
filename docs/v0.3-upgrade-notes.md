## P1 安全

- `/admin/{ratelimit,storage,notifies}` 三组路由补 AdminMiddleware（此前匿名可改限流/存储配置）
- 登录/取件**失败计数锁定**（IP+账户，Redis/内存双模，错误码 10011）
- **可信代理解析**：security.trusted_proxies CIDR + XFF 从右向左；未配置 = 忽略代理头（防伪造）
- **魔数校验**（PE/ELF/Mach-O/shebang）+ 扩展名白名单优先 + 直传分享补黑名单
- 文件名消毒（剥路径/控制字符/限长保扩展名）
- 存储端点 **SSRF**：scheme 白名单 + DNS 解析复判私网（默认拒绝，NAS 局域网部署显式放行）
- 取件**下载令牌**：HMAC 时间窗 + 恒时比较；取件接口下发、`/share/download` 强制（密码可替代）
- 文本分享 222KB 上限；**logout**（token 黑名单，两套认证中间件均校验）+ **check-auth** 端点
- 限流 BlockSeconds 生效 + Redis 固定窗口模式；admin ratelimit status/test 接真实数据

## 部署注意

> ⚠️ 本节变量名为 2026-10-08 前的旧 `FCB_*` 前缀，已随生态 `PB_*` 全量更名**失效（无双读兼容）**；现行名单见 [ENVIRONMENT_VARIABLES.md](ENVIRONMENT_VARIABLES.md)，照抄旧名会静默失效。

- 反向代理部署**必须**配 `FCB_TRUSTED_PROXIES`，否则真实客户端 IP 不可见（限流按代理 IP 计）
- 局域网对象存储/WebDAV 需 `FCB_SSRF_ALLOW_PRIVATE=true`
- Redis 建议启用（匿名取件必需）；多副本部署还需 `FCB_RATE_LIMIT_USE_REDIS=true`
  - 勘误（2026-10-06）：core 单机内存模式落地后（随下版发布），匿名取件降为"建议"——`FCB_REDIS_HOST` 置空即单机内存模式（全功能，重启丢失未取件映射），Redis 仅剩持久化价值；此前版本仍按上文
- 前端下载链接改为消费服务端下发的 `download_url`（带令牌），旧版手工拼接的 URL 在令牌开启后将 401
